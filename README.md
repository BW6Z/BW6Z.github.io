# BW6Z.github.io

Personal portfolio for Yudi Zheng, published with GitHub Pages.

- `index.html`: profile, research experience, selected projects, education, and community activities.
- `repod.html`: Repod hackathon project overview, model setup, recorded results, and engineering lessons. Linked from Selected Projects.
- `profile.jpg`: profile portrait.

The site uses plain HTML and CSS, with no build step or dependencies. Open `index.html` directly, or serve the repository with a local static file server.

Repod results are drawn from [the project’s recorded real runs](https://github.com/BW6Z/Repod#results-from-real-runs). The project page links to the source repository and the public read-only replay.
